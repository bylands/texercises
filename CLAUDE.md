TeXercises is an online platform for physics and math exercises written in LaTeX. The editor provides four main parts for each exercise:
1. Solver: Contains the given quantities (\NewQty), conversions and solutions (\SolQty). The [Cheatsheet](file://cheatsheet.md) provides more insight into the syntax.
2. Exercise Text: Contains the text of the exercise. It can refer to quantities defined in the Solver part, usually using the notation \XO to include the literal value of a quantity defined as X. Typical examples for mathematical syntax can be found in [syntax](file://syntax.png).
3. Solution: Contains the solution with all the necessary explanations, formal and numerical calculations. It can refer to quantities defined in the Solver part as \XF (formal solution), or \X (numerical value).
4. Short Solution: Contains the (usually numerical) results only.

The file [examples](file://examples.md) contains some examples, structured according to parts 1 to 4.
